# MiDoG-Self
Contains the submission made to MiDoG 2025 workshop.

## About the project

This project develops an architecture comprising three modules: MixStyle, CBAM, and EMA Teacher, to achieve robust cross-domain performance in the classification of atypical mitoses across species, tissue types, and various staining protocols.

#### MixStyle

To create variations in the stain types and coloring without affecting the structure, and to learn variations in non-morphological features.

#### CBAM

To pay attention spatially and temporally to important features, even among all the morphological features. Highlights important in important features.

#### Knowledge Distillation with EMA Teacher

To allow the model to have stabilized learning
